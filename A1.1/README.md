# A1.1 — Análisis del nivel de obesidad

## Descripción
En esta actividad se analizaron datos sobre características y hábitos de las personas para estudiar su relación con el nivel de obesidad.

## Archivos
- `A1.1 625784.ipynb`: contiene el código, las gráficas y los resultados.
- `A1.1 625784.html`: permite consultar la actividad en el navegador.
- `A1.1 Obesidad.csv`: contiene los datos utilizados.

## Cómo reproducir los resultados
1. Descarga todos los archivos de esta carpeta.
2. Abre el archivo `.ipynb` en VS Code o Jupyter.
3. Verifica que el archivo `.csv` esté en esta misma carpeta.
4. Ejecuta las celdas del notebook en orden, desde la primera hasta la última.
