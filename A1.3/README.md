# A1.3 — Análisis de calificaciones

## Descripción

En esta actividad se utiliza Python para cargar y explorar una base de datos de calificaciones. El notebook presenta el análisis y organiza sus resultados mediante tablas.

## Archivos

- `A1.3 625784.ipynb`: código, análisis y resultados.
- `A1.3 625784.html`: versión de la actividad para consultar en un navegador.
- `A1.3 Calificaciones.csv`: base de datos utilizada.

## Cómo reproducir los resultados

1. Descarga los archivos de esta carpeta.
2. Abre `A1.3 625784.ipynb` en VS Code o Jupyter.
3. Deja `A1.3 Calificaciones.csv` en la misma carpeta que el notebook.
4. Ejecuta las celdas en orden, desde la primera hasta la última.

Para ver los resultados sin ejecutar el código, abre `A1.3 625784.html` en un navegador.
