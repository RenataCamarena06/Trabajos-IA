# Trabajos de Inteligencia Artificial

Este repositorio reúne mis actividades y proyectos de Inteligencia Artificial. En cada trabajo aplico herramientas de análisis de datos y aprendizaje automático a un problema diferente.

## Actividades y proyectos

| Actividad | Tema | Archivos |
|---|---|---|
| [A1.1](A1.1/) | Análisis del nivel de obesidad | Notebook, versión HTML y base de datos |
| [A1.2](A1.2/) | Relación entre felicidad y producto interno bruto mediante regresión | Notebook, versión HTML y base de datos |
| [A1.3](A1.3/) | Análisis de datos de calificaciones | Notebook, versión HTML y base de datos |
| [P P1](P%20P1/) | Proyecto del primer parcial: análisis del consumo excesivo de alcohol | Notebook, versión HTML y base de datos |
| [A2.1](A2.1/) | Clasificación del consumo excesivo de alcohol con regresión logística | Notebook, versión HTML y base de datos |
| [A2.2](A2.2/) | Clasificación de datos de estudiantes con LDA y árboles de decisión | Notebook, versión HTML y base de datos |
| [A2.3](A2.3/) | Clasificación de flores Iris con Random Forest, Boosting, SVM y redes neuronales | Notebook, versión HTML y base de datos |

Cada actividad tiene su propia carpeta. Dentro encontrarás un `README.md` que explica el trabajo, los archivos incluidos y los pasos para reproducir sus resultados.

## Cómo consultar los trabajos

Haz clic en el nombre de una actividad en la tabla para entrar a su carpeta. Puedes abrir el archivo `.ipynb` para revisar el código y los resultados, o descargar su versión HTML y abrirla en el navegador.

## Cómo reproducir los resultados

1. Descarga los archivos de la actividad que te interese, incluida su base de datos.
2. Abre el notebook en VS Code, Jupyter Notebook o JupyterLab.
3. Instala las bibliotecas indicadas en el trabajo.
4. Verifica la ubicación de los datos y ejecuta las celdas en orden.

Consulta el `README.md` de cada actividad para seguir sus instrucciones específicas. En A2.3, la ejecución de la red neuronal requiere TensorFlow; también puede realizarse en Google Colab cargando la base de datos.
