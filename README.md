# Trabajos de Inteligencia Artificial

Este repositorio reúne mis actividades de Inteligencia Artificial. En cada trabajo aplico herramientas de análisis de datos y aprendizaje automático a un problema diferente.

## Actividades

| Actividad | Tema | Archivos |
|---|---|---|
| [A1.1](A1.1/) | Análisis del nivel de obesidad | Notebook, versión HTML y base de datos |
| [A1.2](A1.2/) | Relación entre felicidad y producto interno bruto mediante regresión | Notebook, versión HTML y base de datos |
| [A1.3](A1.3/) | Análisis de datos de calificaciones | Notebook, versión HTML y base de datos |
| [P P1](P%20P1/) | Proyecto: análisis del consumo excesivo de alcohol | Notebook, versión HTML y base de datos |
| [A2.1](A2.1/) | Clasificación del consumo excesivo de alcohol con regresión logística | Notebook, versión HTML y base de datos |
| [A2.2](A2.2/) | Clasificación de datos de estudiantes con LDA y árboles de decisión | Notebook, versión HTML y base de datos |

Cada actividad tiene su propia carpeta. Dentro encontrarás un `README.md` que explica el trabajo y los pasos para reproducir sus resultados.

## Cómo consultar los trabajos

Haz clic en el nombre de una actividad en la tabla para entrar a su carpeta. Puedes abrir el archivo `.ipynb` para revisar el código y los resultados, o consultar su versión HTML cuando esté disponible.

## Cómo reproducir los resultados

Descarga los archivos de la actividad que te interese, incluidos sus datos. Después, abre el notebook en VS Code o Jupyter y sigue las instrucciones de su `README.md`.
