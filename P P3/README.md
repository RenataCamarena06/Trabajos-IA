# Proyecto — Análisis de datos genéticos y supervivencia en cáncer cervicouterino

## Descripción

Este proyecto analiza datos de cáncer cervicouterino del conjunto CESC. Se exploran datos de expresión genética y variables clínicas para identificar patrones y estudiar su relación con la supervivencia.

El notebook contiene el código, las gráficas y los resultados del análisis. El documento presenta la explicación del procedimiento, las interpretaciones y las conclusiones.

## Archivos

- `P_P3_625784.ipynb`: notebook con el desarrollo del proyecto.
- Reporte del proyecto: descripción de los datos, metodología, resultados y referencias.
