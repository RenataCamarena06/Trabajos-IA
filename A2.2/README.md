# A2.2 — Clasificación con LDA y árboles de decisión

## Descripción

En esta actividad se analiza la base de datos de estudiantes portugueses para comparar modelos de clasificación. Se utiliza la calificación final (`G3`) y otras características de los estudiantes para explorar los datos, entrenar modelos de análisis discriminante lineal (LDA) y árboles de decisión, y evaluar sus resultados.

También se compara un árbol sin poda con uno podado para estudiar cómo cambia su desempeño.

## Archivos

- `A2.2 625784.ipynb`: notebook con el análisis, los modelos, las gráficas y la evaluación.
- `A2.2 625784.html`: versión del trabajo para consultar en el navegador.
- `student-por.csv`: base de datos necesaria para ejecutar el notebook.

## Cómo reproducir los resultados

1. Descarga los tres archivos y guárdalos en una misma carpeta.
2. Abre `A2.2 625784.ipynb` en Jupyter Notebook, JupyterLab o VS Code.
3. Instala las bibliotecas de Python que aparecen al inicio del notebook.
4. Ejecuta todas las celdas en orden. El notebook debe leer `student-por.csv` desde la misma carpeta.

Si solo quieres ver el trabajo terminado, abre `A2.2 625784.html` en tu navegador.
