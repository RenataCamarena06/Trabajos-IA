# A3.3 — Tutorial de aprendizaje por refuerzo

## Descripción

Este tutorial presenta paso a paso cómo un agente aprende a interactuar con un entorno mediante acciones y recompensas.

Se compara el comportamiento de un agente aleatorio con el de un agente entrenado, utilizando los resultados de las evaluaciones y un video para observar su desempeño.

## Contenido

- Preparación del entorno.
- Exploración de estados, acciones y recompensas.
- Evaluación de un agente aleatorio como referencia.
- Entrenamiento del agente.
- Comparación de las recompensas obtenidas.
- Visualización del comportamiento mediante video.
- Interpretación de resultados y conclusiones.

## Archivos

- Notebook `.ipynb`: código, explicaciones y resultados del tutorial.
- Documento del tutorial: procedimiento e interpretación de los resultados.
- Video generado al ejecutar las celdas de visualización.

## Datos y entorno

Los datos de entrenamiento se generan mediante la interacción del agente con el entorno de simulación. No es necesario descargar una base de datos externa.

## Cómo ejecutar el tutorial

1. Abre el notebook en Google Colab.
2. Ejecuta las celdas de instalación de dependencias.
3. Ejecuta las importaciones y la configuración del entorno.
4. Continúa con las celdas en orden para evaluar al agente aleatorio y entrenar al agente.
5. Ejecuta la evaluación y las celdas que generan el video.

El entrenamiento puede tardar varios minutos. Las recompensas y el comportamiento pueden variar entre ejecuciones debido a los componentes aleatorios del proceso.

## Objetivo de aprendizaje

Comprender cómo las acciones y las recompensas influyen en el aprendizaje de un agente, y evaluar si el entrenamiento mejora su comportamiento respecto a una estrategia aleatoria.
