# A2.1 — Clasificación del consumo excesivo de alcohol

## Descripción

En esta actividad se utiliza regresión logística para clasificar la prevalencia de consumo excesivo de alcohol por estado. El análisis parte de la base de datos incluida en esta carpeta y considera variables de salud como la prevalencia de tabaquismo, sobrepeso y obesidad.

## Archivos

- `A2.1 625784.ipynb`: notebook con la preparación de datos, el entrenamiento y la evaluación del modelo.
- `A2.1 625784.html`: versión HTML para consultar el análisis sin ejecutar código.
- `basededatosfinal.csv`: base de datos necesaria para reproducir los resultados.

## Cómo reproducir los resultados

1. Descarga los tres archivos y guárdalos en la misma carpeta.
2. Abre `A2.1 625784.ipynb` en Jupyter Notebook, JupyterLab o VS Code.
3. Instala las bibliotecas de Python indicadas en las primeras celdas del notebook.
4. Ejecuta las celdas en orden, desde la primera hasta la última.

El notebook debe poder encontrar `basededatosfinal.csv` en la misma carpeta. Para consultar los resultados sin ejecutar el código, abre `A2.1 625784.html` en tu navegador.
