# A1.2 — Regresión lineal y felicidad

## Descripción

En esta actividad se estudia la relación entre la felicidad y distintos indicadores de los países. Primero se analiza la relación entre felicidad y producto interno bruto (GDP). Después se consideran otras variables, como esperanza de vida, desempleo y control de la corrupción, para construir y evaluar modelos de regresión.

## Archivos

- `A1.2 Regresión Lineal.ipynb`: código, análisis, gráficas y resultados.
- `A1.2 Regresión Lineal.html`: versión del trabajo para consultar en el navegador.
- `A1.2 Felicidad y GDP.csv`: datos de felicidad y GDP.
- `esperanza.csv`: datos de esperanza de vida.
- `desempleo.csv`: datos de desempleo.
- `controlcorrupcion.csv`: datos de control de la corrupción.

## Cómo reproducir los resultados

1. Descarga todos los archivos de esta carpeta.
2. Abre `A1.2 Regresión Lineal.ipynb` en VS Code o Jupyter.
3. Mantén los cuatro archivos CSV en la misma carpeta que el notebook.
4. Ejecuta las celdas en orden, desde la primera hasta la última.

Para consultar los resultados sin ejecutar el código, abre `A1.2 Regresión Lineal.html` en un navegador.
